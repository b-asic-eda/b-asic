How to cite B-ASIC
------------------

If you use B-ASIC in your research, please cite it.
There is currently no dedicated publication to cite,
so please refer to this documentation or the
`repository <https://github.com/b-asic-eda/b-asic>`__ for the time being.
A citable reference will be provided here once available.
